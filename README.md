# IPTV TV 版（Android 4.4+ / 电视大屏 / 遥控器优化）

手机版的完整功能复刻，专为**电视大屏**与**遥控器操作**深度优化，最低支持 **Android 4.4（API 19）**。

## 核心特性

### 完整复刻手机版功能
- **全网直播源采集**：20+ 内置订阅源，多镜像回退、自动去重整理
- **有效性检测**：并发检测，检测后自动清除无效源
- **多格式导出**：M3U / M3U8 / TXT / JSON / TVBox / XSPF / CSV 七种格式
- **内置播放器**：ExoPlayer 2.x，支持 HLS/DASH/RTSP，倍速、音轨、字幕、画面比例、画中画
- **频道列表**：搜索、分组、按来源分类（网络采集源/网络直播源/TVBox源）、多订阅 ①②③ 后缀编号
- **直播源导入**：网址 / 文件 / 剪贴板
- **TVBox 源导入**：自动展开 lives 订阅为可播放频道
- **频道管理**：每个频道可自行删除、批量管理、回收站恢复
- **来源隔离**：重新采集只更新采集源，其他来源频道互不影响

### 电视大屏优化
- **左侧导航栏**：横屏大屏布局，导航常驻左侧，内容区占据主要视野
- **大字号大按钮**：全局字号与按钮放大（56dp 按钮、18sp 文字），适合远距离观看
- **两列频道网格**：横屏一屏浏览更多频道
- **焦点高亮**：卡片/按钮/Chip 获得焦点时描边 + 放大动画，焦点位置清晰可见

### 遥控器深度优化
| 页面 | 操作 |
|------|------|
| 主界面 | 数字键 `1/2/3` 快速切换 采集/频道/设置；方向键移动焦点；返回键双击退出 |
| 播放器 | 数字键输入频道号直接跳转；左/右快退/快进 5 秒；上/下音量；频道 +/- 或媒体键换台；快进/快退键 ±10 秒；菜单键播放设置；信息键频道详情；返回键隐藏控制栏/退出 |
| 全局 | 所有可交互控件支持焦点导航与高亮反馈 |

## Android 4 兼容说明

- **minSdk 19（Android 4.4 KitKat）**：覆盖绝大多数安卓 4.x 智能电视/电视盒子
- 依赖全部降级到支持 API 19 的版本；播放器采用 ExoPlayer 2.18（Media3 需 API 21，不兼容）
- 开启 Java 8 API desugaring 与 MultiDex，保证在低版本系统上运行
- Android 4.4 无 SAF 目录选择（API 21+），导出自动降级到应用外部存储 `Download/IPTV`

> 说明：Android 4.0/4.1/4.2（API 14-17）因现代依赖库与播放器最低要求，未纳入兼容范围。如需支持请反馈。

## 与手机版的关系

- 包名不同（`com.iptv.tv`），可与手机版同时安装，数据相互独立
- 功能与手机版保持一致，界面针对电视重新设计

本项目仅提供工具能力，请遵守当地法律法规，仅播放合法授权的直播内容。
